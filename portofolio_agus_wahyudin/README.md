# Portofolio Agus Wahyudin

Website portofolio personal yang dibuat untuk memperkenalkan diri, pendidikan, keterampilan, proyek, dan informasi kontak saya. Website ini dibuat dengan HTML dan CSS murni, serta dirancang agar tampil rapi, modern, dan responsif.

## Deskripsi

Portfolio ini berfungsi sebagai halaman digital personal yang menampilkan:

- Profil singkat dan intro
- Informasi pendidikan
- Keterampilan yang sedang dikembangkan
- Proyek pilihan
- Informasi kontak

Tujuan utama dari website ini adalah untuk menampilkan identitas dan kemampuan saya secara profesional kepada calon rekan, pembaca, atau pihak yang tertarik dengan karya dan kemampuan saya.

## Teknologi yang Digunakan

- HTML5
- CSS3
- Responsive design
- Teknik layout modern tanpa framework

## Struktur Project

```bash
portofolio_agus_wahyudin/
├── index.html
├── style.css
├── images/
│   └── foto.jpeg
└── README.md
```

## Fitur Utama

- Navigasi halaman yang mudah dipahami
- Hero section dengan judul dan intro personal
- Bagian tentang saya
- Timeline pendidikan
- Kartu keterampilan
- Section proyek pilihan
- Informasi kontak dan sosial media
- Tampilan yang responsif di berbagai ukuran layar

## Cara Menjalankan

### 1. Buka folder project
Buka folder `portofolio_agus_wahyudin` di editor atau direktori lokal Anda.

### 2. Jalankan halaman website
Ada beberapa cara:

- Buka file `index.html` langsung di browser
- Atau gunakan ekstensi seperti Live Server di VS Code untuk melihat tampilan secara real-time

### 3. Lihat hasil
Website akan terbuka dan menampilkan halaman portofolio lengkap.

## Catatan

- Foto profil dapat diganti di folder `images/` dengan file yang sesuai.
- Jika file foto belum ada, website akan menampilkan placeholder yang sudah disediakan.
- Anda dapat menyesuaikan isi teks seperti nama, pendidikan, keterampilan, proyek, dan kontak sesuai data pribadi Anda.
